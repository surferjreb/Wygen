# Wygen
###  **A simple program to transfer wiegand card numbers to binary for input to a security panel via a device interface**

> This program takes a card or card range and outputs to a text file.  This text file can be used on a device to send a security panel valie or invalid cards to test system.  The device I am currently using for this is a Raspberry Pico.  The program for this can be found in the folder Pico code.  That progam is written in MicroPython.
